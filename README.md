## Title
The friction-era VOS amplitude of a $\mathbb{Z}_2$ string network from nematic disclination data

## Abstract
In the overdamped limit of the velocity-dependent one-scale (VOS) model the coarsening law is $L\propto t^{1/2}$ for every value of the momentum parameter $k$, the sink coefficient $\tilde{c}$ and the curvature ratio $\lambda\equiv R/L$, which enter the attractor only through the amplitude $\mathcal{A}=\kappa(\kappa+\tilde{c})$ with $\kappa\equiv k/\lambda$. The exponent, which is what liquid-crystal experiments have tested, therefore constrains none of them. We measure $\mathcal{A}$ from the nematic disclination data of Chuang, Turok and Yurke, whose companion loop-collapse measurement fixes the transport coefficient $\ell_ {d}=T/\Gamma$ on the same samples, so that the material constants of 5CB cancel. Treating the unmatched per-quench value of $\ell_ {d}$ as a nuisance parameter with a Gaussian prior and marginalizing it analytically, we obtain $\mathcal{A}=10.0^{+1.3}_ {-1.1}$ from the three quenches taken in the 234 μm cell, whose individual amplitudes agree within their errors. The fourth quench, the only one taken in the 158 μm cell, gives $\mathcal{A}=3.0^{+0.8}_ {-0.6}$; we fit and report it separately rather than excluding it. Converting either amplitude into $\tilde{c}$ requires $\lambda$, which these data do not determine, so we report the constraint as the curve $\tilde{c}(\lambda)=\mathcal{A}\lambda/k-k/\lambda$. At $\lambda=1$ and with $k\le1$ the two amplitudes give $\tilde{c}\ge9.0^{+1.3}_ {-1.1}$ and $\tilde{c}\ge2.0^{+0.8}_ {-0.6}$, against $\tilde{c}=0.23$–$0.57$ from relativistic $U(1)$ simulations, which are reached only at $\lambda\simeq0.33$–$0.35$ and $0.62$–$0.68$. We are not aware of a VOS calibration for a cosmological $\mathbb{Z}_ {2}$ network, so the excess cannot be attributed to topology alone, and we list what a repeat experiment would have to measure to turn the curve into a number.
